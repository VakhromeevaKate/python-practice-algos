### Как сдавать ДЗ.

Оформление ДЗ:
1. Форкаете себе репозиторий
2. Создаете файл по шаблону: ```hw-<номер домашки>-<фамилия>-<и>-<о>.ipynb``` (например, hw-1-vakhromeevae-e-a.ipynb) в директории своей группы ```636-01/HomeWorks/ || 636-02/HomeWorks/```.
3. Решаете задание (проверяйте как минимум все данные тесты, но лучше придумать еще свои краевые условия).
4. Оцените сложность вашего решения по времени и по памяти (O(n) - наихужший случай).
5. Выставите PR в репозиторий (ВАЖНО!!! Выставить PR необходимо в ветку ```student```).
6. Готово!
